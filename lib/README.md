# Lib

## Purpose

Contains reusable server-side evaluation logic shared by Question Machine's request handlers and tests.

## Contents

- `evaluator.mjs` — Scores submitted answers with deterministic checks and optional semantic-evaluation support.

## Responsibilities

Reusable server-side logic belongs here. Browser rendering and static assets belong in `public/`.

## Important Notes

- This folder is part of **Question Machine** and should be kept consistent with the commands and architecture documented in the root README.
- Paths and file roles listed above reflect the current repository implementation.
