# Public

## Purpose

Contains the static browser client served by Question Machine's local HTTP server.

## Contents

- `app.js` — Implements the browser interaction flow for loading questions, submitting answers, and displaying evaluation feedback.
- `index.html` — Provides Question Machine's browser document, controls, and accessible result regions.
- `styles.css` — Defines the responsive visual design and interaction states for Question Machine's browser interface.

## Responsibilities

Browser-only HTML, CSS, and JavaScript belong here. Server-side validation and secrets must never be embedded in these files.

## Important Notes

- This folder is part of **Question Machine** and should be kept consistent with the commands and architecture documented in the root README.
- Paths and file roles listed above reflect the current repository implementation.
